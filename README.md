# 🌍 Language Learning App

An interactive and modern language learning application built with React. This app helps users learn new words and phrases in multiple languages using translation APIs, pronunciation support, flashcards, and quizzes.

---

## 🚀 Features

### 🌐 Multi-Language Support

Learn words and phrases in:

* Spanish 🇪🇸
* French 🇫🇷
* German 🇩🇪
* Japanese 🇯🇵
* Korean 🇰🇷
* Chinese 🇨🇳
* Italian 🇮🇹
* Portuguese 🇵🇹
* Russian 🇷🇺
* Hindi 🇮🇳

### 🔤 Smart Translation

* Translate any English word or phrase instantly.
* Powered by the MyMemory Translation API.
* Dynamic translations without hardcoded data.

### 🔊 Pronunciation Support

* Listen to translated words using the browser's Speech Synthesis API.
* Supports pronunciation for multiple languages.

### 💾 Flashcard System

* Save translated words as flashcards.
* Create your own personalized vocabulary deck.
* Delete unwanted flashcards anytime.

### 🧠 Quiz Mode

* Test your learning progress.
* Translate words from memory.
* Score tracking for practice sessions.

### 📈 Progress Tracking

* Learning progress indicator.
* Quiz score tracking.
* Progress automatically saved locally.

### 💻 Responsive Design

* Desktop-friendly dashboard layout.
* Mobile responsive interface.
* Modern glassmorphism-inspired UI.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/dhanushY05/language-learning-app.git
```

Navigate into the project directory:

```bash
cd language-learning-app
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:5173
```
